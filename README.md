# Capture The Flaginator

Add a description of your project here.
A fun web game that takes the BYUI map and turns it into a capture the flag game where you can play with your friends. 
It will utilize multiple buildings on campus and allows the players to hide their flag in a select room.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Run npx live-server in terminal
2. Select game/start_game.html
3. Click Host Server button
4. Duplicate tab and click Join Server
5. Wait for a server to pop up
6. Click it and see the players.

Instructions for using the software:

1. WASD to move
2. Space bar to pick up flag
3. M to sprint
4. Space to drop flag in zone
